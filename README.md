# Flutter Login UI

A basic Flutter login screen that demonstrates stateful widgets, form fields, secure password handling, and simple user validation with hardcoded user data.

## 🖼️ Preview

This app features:
- A login form with email and password fields.
- Password visibility toggle.
- Simple validation using a hardcoded user list.
- Material 3 design and themed UI.


## 🚀 Getting Started

Follow these steps to run the app locally:

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- An IDE like [Android Studio](https://developer.android.com/studio) or [VS Code](https://code.visualstudio.com/)
- An emulator or physical device

🧪 Features

    ✅ Email and password input validation
    ✅ Toggle password visibility
    ✅ AppBar with icons
    ✅ Responsive column layout using SingleChildScrollView
